# DualPath

DualPath is an agentic RAG system that answers questions from two kinds of data at once: a SQL warehouse (DuckDB, built from CSVs of sample health-plan claims) and a document corpus (policy documents in Markdown, text and PDF, embedded locally into Chroma). A LangGraph state machine sends each question to SQL, the documents, both, a direct reply, or a refusal. Generated SQL goes through a parser-based firewall and runs on a read-only, row-capped, time-limited connection. Failed queries are repaired automatically, and answers are self-critiqued and cited. It also keeps conversational memory and can pause for a human to approve the SQL before it runs. You can use it as a CLI (`dualpath ask`, `dualpath chat`), a FastAPI service (`dualpath serve`), or a Streamlit UI (`dualpath ui`), all on Groq-hosted models.

What's still missing: there is no evaluation harness yet (golden questions, result-set metrics, `dualpath evaluate`), so answer quality hasn't been measured. There is also no automated test suite and no publishing setup such as a Makefile, CI or releases. The API has no authentication, so don't expose it publicly. The default Groq model names in the config may be retired, so check `dualpath doctor` and set `DP_GEN_MODEL`, `DP_SQL_MODEL` and `DP_UTIL_MODEL` to models your key can use. This is a personal side project. I don't have the time to keep working on it or to contribute much going forward, so treat it as-is. You're welcome to fork it and take it further.
